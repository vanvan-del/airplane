# 排版工作台

一个自用的网页排版编辑器，单个 HTML 文件，不需要安装任何东西，也不需要联网。

## 启动

- **Mac**：双击 `start-mac.command`（第一次如果被系统拦住，右键 → 打开）
- **Windows**：双击 `start-windows.bat`
- **Linux**：运行 `./start-linux.sh`

脚本会在本机 `http://127.0.0.1:8173/` 打开编辑器，用完关掉终端窗口即可。
电脑上没有 Python 时，脚本会直接用浏览器打开 `index.html`，也能用。

> 数据保存在浏览器里，并且跟打开方式绑定：用启动脚本打开和直接双击 `index.html` 打开，是两份不同的数据。建议固定用启动脚本。换电脑或清理浏览器数据前，请先「导出」备份。

## 功能

- **多个页面**：「＋ 新页面」新建，双击页面标签或点「重命名」改名，点标签切换。每个页面单独保存布局和画布尺寸。
- **共用素材库**：上传图片（支持透明 PNG），也可以把图片拖进窗口或直接粘贴。点素材就放到当前页面。
- **直接在画布上操作**：拖动移动；拖四个角的方块缩放；拖上方的圆点旋转（按住 Shift 每 15° 吸附）。点击时只会选中图片里不透明的部分。
- **图层**：像 Photoshop 一样，最上面的在最前；拖动左边的 ⋮⋮ 调整顺序；可以隐藏、锁定、删除。删除图层不会删除素材库里的原图。
- **撤销 / 重做**：Ctrl+Z / Ctrl+Shift+Z（Mac 用 ⌘）。
- **快捷键**：Delete 删除选中图层，方向键微调 1px（加 Shift 10px），Esc 取消选中。
- **自动保存**：每次修改后自动保存，右上角显示保存时间。
- **多窗口同步**：同时开多个窗口时，一个窗口里的修改会自动同步到其他窗口。
- **预览**：全屏查看成品效果，← → 翻页，Esc 关闭。
- **导入 / 导出**：导出为一个 `.json` 文件，里面包含所有页面和素材图片；导入会替换当前项目（会先确认）。也可以直接把 `.json` 拖进窗口导入。
