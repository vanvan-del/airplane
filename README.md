# ✈️ 小飞机去旅行

一个游戏风格的旅游 App：输入出发地和目的地，卡通小飞机飞过去，落地后用图标的方式展示：

| 图标 | 内容 |
| --- | --- |
| 🚄 交通比价 | 高铁 / 普速火车 / 飞机的估算价格和耗时，标出「最省钱」「最快」，并有携程、去哪儿、12306 的直达购票链接 |
| 🏞️ 必去景点 | 景点介绍、门票参考、高德导航 |
| 📸 打卡拍照 | 拍照机位和拍摄建议 |
| 🌤️ 天气穿搭 | 出行当天的温度、天气、降水概率，以及穿搭建议 |
| 🍜 地道美食 | 当地特色美食，附高德、小红书搜索 |
| 🗺️ 推荐路线 | 按天安排的游玩路线 |
| 🎫 门票指南 | 各景点门票参考价和预约提醒 |

## ⭐ 定制攻略

内置 34 个城市的攻略：国内 14 个热门城市，加上巴黎、伦敦、罗马、佛罗伦萨、威尼斯、巴塞罗那、阿姆斯特丹、柏林、布拉格、维也纳、布达佩斯、里斯本、雅典、伊斯坦布尔、东京、京都、首尔、曼谷、新加坡、纽约。每个景点都标了兴趣分类、所在片区、建议游玩时间和历史故事。

在目的地页面点「定制攻略」，回答三个问题：

1. 喜欢什么：人文历史、自然风景、拍照打卡、艺术博物馆、名人足迹、运动户外、夜景夜生活（可多选）
2. 玩几天：1 到 7 天
3. 节奏：轻松慢游、正常节奏、特种兵

App 会按喜好挑景点，同一片区的排在同一天，分成上午、下午、晚上，每天推荐当地美食，并附上城市和每个景点的历史故事。没收录的城市会用维基百科查附近的景点临时生成。

## 👫 旅行伙伴和旅行回放

- 每个人都可以做一个自己的像素角色（肤色、发型、发色、衣服、配饰）。
- 在足迹的记忆页里，点日期选上这次和谁一起去的。
- **邀请朋友**：生成邀请码或邀请链接发给朋友，朋友打开后就会出现你的角色和你们一起去过的地方；朋友再把他自己的邀请码发给你，你就有了他亲手设计的角色。数据都存在各自手机上，没有服务器。
- **旅行回放**：在像素世界地图上，按日期一站一站播放：小飞机飞过去，国家点亮，角色在目的地跳一跳，对话框写出“我、小明 抵达 罗马（意大利）！”。可以看全部旅行，也可以只看和某个朋友的。

## 🖼️ 照片变像素风

照片添加后会自动变成像素画：缩小成 48 格宽，再换成 App 的 16 色调色板（另加几种肤色），叠一点有规律的抖动。全部在手机上计算，照片不会上传。在记忆页可以切换「像素风 / 原图」，旅行回放里每一站会弹出一张像素拍立得。

## 💾 数据备份

足迹、伙伴和照片只存在这台设备上。在「我的足迹」页面底部可以导出备份文件（照片会一起打包），换手机后用「从备份恢复」导回来。

## 🗺️ 我的足迹

- 在目的地页面点「📍 我去过这里」，这个城市就会在足迹地图上点亮一面小旗子；也可以在足迹页补录以前去过的城市。
- 每个去过的地方都有一个**记忆相册**：可以从手机相册选照片，或者直接拍照，再写一段文字记下当时的回忆。
- **足迹地图**用的是高德地图（国内能正常打开、中文地名），能看到全世界的国家和城市，去过的城市插着小旗子，点小旗子打开那里的记忆。
- **扫描相册，自动点亮**：读取相册里照片的拍摄地点，自动识别你去过的城市，并把那里拍的照片放进对应的记忆相册（只是引用相册原图，不会多占空间）。需要允许访问「所有照片」；安卓还需要定位权限来把坐标识别成城市名。
- 手动添加的照片会复制一份存在 App 里，就算相册里的原图删了，记忆也还在。数据只存在你自己的手机上。

内置了 14 个热门城市的攻略（北京、上海、广州、深圳、成都、重庆、西安、杭州、南京、厦门、三亚、长沙、青岛、大理）。其他城市也能查天气和交通，景点和美食会提供小红书 / 高德 / 百度的搜索链接。

## 运行

用 [Expo](https://expo.dev) 开发，iOS 和安卓通用。

```bash
npm install
npx expo start
```

手机上装 **Expo Go**，扫终端里的二维码就能打开。

## 网页版

**在自己电脑上用（功能最全）**：装好 [Node.js](https://nodejs.org) 后运行

```bash
npm install
npm run web
```

浏览器会打开 App，天气、高德地图、购票链接都能正常使用。

**发布成网站，手机浏览器也能打开**：运行 `npm run build:web`，会生成 `dist/` 文件夹，里面就是整个网站。仓库是私有的，GitHub 自带的网页托管要付费，推荐这两个免费方式（都支持私有仓库）：

- [Vercel](https://vercel.com) 或 [Cloudflare Pages](https://pages.cloudflare.com)：用 GitHub 登录，导入这个仓库，构建命令填 `npm run build:web`，输出目录填 `dist`。之后每次推送代码都会自动更新网站。

网页版里「选一批照片，自动点亮」会读取照片里记录的拍摄地点。手机浏览器上传照片时常常会去掉位置信息，所以在电脑上选照片，或者用手机 App 扫描，识别得更准。

## 说明

- 天气数据来自 [Open-Meteo](https://open-meteo.com)，免费、不需要密钥，可查未来 16 天。
- 票价是按距离估算的参考区间，**不是实时票价**；实时最低价请点直达链接到购票平台查看。以后可以接入付费票价接口来显示实时价格。
- 门票价格为参考，请以景区官方公布为准。

## 目录结构

```
App.tsx                  页面切换：首页 → 飞行动画 → 结果页
src/screens/             首页、结果页、足迹页、记忆相册页
src/components/          云朵、飞行动画、各个详情面板
src/services/            地名解析、天气、票价估算和购票链接、穿搭建议、足迹和照片存储
src/data/cities.ts       城市坐标和攻略数据
```
